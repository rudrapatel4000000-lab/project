# Rudra's DevLog — Code, Bugs & Late Night Experiments

A fast, clean, and authentic developer blogging platform handcrafted with **Tailwind CSS**, **Lucide Icons**, and **Marked.js**.

## Features

- **Personal Brand & Identity**: Rudra's personal developer journal, thoughts, war stories, and setup notes.
- **Story Stream**: Clean, editorial personal dev posts with estimated reading times and topic chips.
- **Live Search & Tags**: Filter notes by keyword, tag, or category in real-time.
- **Write Studio**: Create and edit notes with live split Markdown preview and tags.
- **Engagements**: Helpful (likes) reaction, Bookmark notes, and interactive comments discussion.
- **Theme**: Dark and Light mode toggle with smooth persistence.
- **Local-First**: All notes, edits, and comments are persisted in the browser via `localStorage`.

## How to Run

1. **Local Server (Active on Port 3000)**:
   ```bash
   node server.js
   ```
   Open `http://localhost:3000`

2. **Direct File**:
   Double click `index.html` to open in any web browser.
